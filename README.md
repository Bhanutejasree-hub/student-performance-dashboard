# student-performance-dashboard

## About the Project
This project is part of my internship at **YR NOVATECH** in the Artificial Intelligence and Machine Learning domain.

The main aim of this task is to understand how to collect, explore, clean, and preprocess a dataset using Python. I worked with a Student Performance dataset to prepare the data for further analysis and machine learning applications.

## Dataset Information
- **Dataset Name:** Student Performance Dataset
- **Original Records:** 1,020
- **Original Columns:** 7
- **Final Records:** 1,000
- **Final Columns:** 9

### Dataset Columns
- Student_ID
- Age
- Gender
- Study_Hours
- Attendance(%)
- Test_Score
- Grade

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed

1. **Data Collection:** Loaded the Student Performance dataset using Pandas.
2. **Data Exploration:** Checked the dataset structure, columns, data types, and statistical information.
3. **Missing Value Handling:** Identified missing values and filled them using suitable methods.
4. **Duplicate Removal:** Identified and removed 20 duplicate records.
5. **Invalid Value Handling:** Checked and corrected invalid values in Study_Hours and Attendance.
6. **Outlier Detection:** Used the IQR method to identify outliers.
7. **Feature Engineering:** Created two new columns:
   - Age_Group
   - Study_Category
8. **Data Export:** Saved the final cleaned dataset as a CSV file.

## Final Dataset Results
- Total Records: 1,000
- Total Columns: 9
- Missing Values: 0
- Duplicate Records: 0

## Conclusion
Through this task, I learned how to explore and preprocess a dataset using Python. I gained practical experience in handling missing values, removing duplicates, correcting invalid data, detecting outliers, and creating new features. This task helped me understand the importance of data preprocessing before performing data analysis or building machine learning models.
